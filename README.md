# exAv1-projeto-de-software-hemocentro-bolsa-de-sangue
O hemocentro do hospital universitário controla bolsas de sangue coletadas de doadores e as requisições feitas pelos centros cirúrgicos.

Requisitos técnicos:
• Python 3.10+; apenas biblioteca padrão + pytest. Nada de ORM, banco, Flask/FastAPI,
requests ou mocks de infraestrutura.
• pytest-q deve rodar verde e em menos de um segundo.
• Nenhum print() dentro de dominio.py.
